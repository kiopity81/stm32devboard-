# STM32F401 Development Board

## Description
STM32F401RET6 development board created using kicad.

## Characteristics
- Power supply via USB Type-C
- Voltage regulator AP2112K-3.3
- SWD connector
- User LED (PA5)
- User button (PA6)
- BOOT0 jumper
- Reset circuit
